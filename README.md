# VerityAI

VerityAI is a small experiment in autonomous, self-modifying code. The scripts
in this repository allow the project to make decisions, evaluate feedback, and
adjust its own behavior by editing its Python modules.

## Installation

Install the required Python packages using pip:

```bash
pip install -r requirements.txt
```

## Running Tests

Use `pytest` to run the unit tests:

```bash
pytest
```
